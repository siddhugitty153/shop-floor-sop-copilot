# BiztelAI Shop-Floor SOP Copilot

> **Rugged, Grounded Manufacturing SOP Copilot for Shop-Floor Supervisors**  
> Strictly grounded RAG assistant built for mobile phones & tablets in precision manufacturing environments (Kaveri Precision Components, Hosur Plant).

---

## 🏭 Operational Overview

In manufacturing facilities, shift supervisors and maintenance personnel face critical procedures across **Safety (LOTO)**, **Preventive Maintenance**, and **Quality Control**. Consulting thick paper manuals or multi-page PDFs during a fast-moving shift is impractical.

The **BiztelAI Shop-Floor SOP Copilot** provides:
- **Strict Grounding with Page Citations:** Every single answer cites the document and page number.
- **Zero Hallucination Refusal:** Explicitly refuses out-of-scope questions (e.g., corporate travel reimbursement) with an amber refusal card.
- **Automated Safety & LOTO Banner:** Automatically flags critical Lockout/Tagout, PPE, high-voltage, and pressure-bleed warnings at the top of the interface.
- **Inline Evidence Snippets:** Supervisors can tap citation badges to expand raw verbatim PDF excerpts without leaving the view.
- **Glove-Friendly Touch Ergonomics ($\ge 48\text{px}$) & Voice Input:** High-contrast industrial palette, one-tap question chips, and browser voice recognition (`webkitSpeechRecognition`).
- **Zero-Config LAN Auto-Discovery:** Seamlessly connects mobile devices over Wi-Fi (`0.0.0.0`).
- **100% Offline & Deterministic:** Vectorized using TF-IDF + FAISS `IndexFlatIP` with multi-tier fallback (Ollama $\to$ Groq $\to$ Extractive fallback) requiring zero model downloads or API keys.

## 🚀 Quick Start Guide

### Prerequisites
- **Python:** 3.11 or 3.12 (`uv` or `pip`)
- **Node.js:** v18+ and `npm`

### 1. Ingest PDFs & Build Vector Store
```bash
# From workspace root
$env:PYTHONPATH = "backend"
backend\.venv\Scripts\python -m app.ingest
```
*Output: Indexes 24 chunks across all 4 plant PDFs in under 5 seconds with zero external network downloads.*

### 2. Start the FastAPI Backend
```bash
$env:PYTHONPATH = "backend"
backend\.venv\Scripts\uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
- API Docs: `http://localhost:8000/docs`
- Health Check: `http://localhost:8000/health`
- Loaded Documents: `http://localhost:8000/documents`

### 3. Start the Mobile-First Frontend
```bash
cd frontend
npm install
npm run dev
```
- Local URL: `http://localhost:5173`
- Network URL: `http://<your-lan-ip>:5173` (e.g. `http://192.168.1.45:5173`)

### 4. Open on Mobile Phone via Wi-Fi
1. Ensure your phone is connected to the same Wi-Fi network as your laptop.
2. Open your phone's browser and navigate to `http://<your-lan-ip>:5173`.
3. The app automatically discovers the FastAPI backend at `http://<your-lan-ip>:8000` with zero configuration!

## 🛡️ Production & Security Considerations

1. **Strict Refusal Boundary:** In precision manufacturing, an erroneous guess on machine specifications can cause catastrophic equipment damage. The system enforces cosine similarity thresholding (`0.085`) to strictly reject any out-of-scope query.
2. **Revision Awareness:** Multiple document revisions (e.g. `QC-SOP-014 Rev03` and `Rev04`) are distinguished with explicit metadata tagging so supervisors know whether an inspection procedure has been superseded.
3. **Emergency Disconnect:** All procedures involving electrical, pneumatic, or hydraulic systems prioritize LOTO reminders before presenting operational instructions.
